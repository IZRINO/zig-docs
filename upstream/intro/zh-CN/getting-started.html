选择正式发布版还是开发版？

一般来说，正式发布版更适合有依赖、重视稳定性的项目；开发版则面向希望参与 Zig 项目开发的人。

Zig 的安装包是自包含的归档文件，可以放在系统中的任意位置。多个版本的 Zig 可以同时存在，互不干扰。

安装 Zig

直接下载

这是获取 Zig 最直接的方式：从下载页面获取适用于你所用平台的 Zig 压缩包，解压到某个目录，再将该目录加入 PATH，就能在任意位置调用 zig。

在 Windows 上设置 PATH

要在 Windows 上设置 PATH，请在 PowerShell 中运行下列代码片段中的一段。根据需要，选择在系统范围内应用此更改（需要以管理员权限运行 PowerShell），还是只对当前用户生效，并且务必修改代码片段，使其指向你的 Zig 所在的位置。C: 前面的 ; 不是笔误。

系统范围（管理员 PowerShell）：

[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "Machine") + ";C:\your-path\zig-windows-x86_64-your-version",
   "Machine"
)

用户范围（PowerShell）：

[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\your-path\zig-windows-x86_64-your-version",
   "User"
)

完成后，重新启动 PowerShell。

在 Linux、macOS 和 BSD 上设置 PATH

将 zig 可执行文件所在的位置加入 PATH 环境变量。

通常的做法是在 shell 启动脚本（.profile、.zshrc……）中添加一行 export。

export PATH=$PATH:~/path/to/zig

完成后，用 source 重新加载启动文件，或者重新启动 shell。

包管理器

Windows

WinGet
Zig 已在 WinGet 上提供。

winget install -e --id zig.zig

Chocolatey
Zig 已在 Chocolatey 上提供。

choco install zig

Scoop
Zig 已在 Scoop 上提供。

scoop install zig

最新开发版：

scoop bucket add versions
scoop install versions/zig-dev

macOS

Homebrew
最新正式发布版：

brew install zig

MacPorts

sudo port install zig

Linux

许多 Linux 包管理器中也提供 Zig。

推荐工具

语法高亮与 LSP

所有主流文本编辑器都支持 Zig 语法高亮，有的内置支持，有的需要安装插件。

如果希望 Zig 与编辑器更深入地集成，可以看看 zigtools/zls。

如果想了解还有哪些工具，请查看工具一节。

运行 Hello World

如果安装过程正确完成，现在应该可以在 shell 中调用 Zig 编译器了。
下面创建你的第一个 Zig 程序来测试一下！

进入你存放项目的目录，运行：

mkdir hello-world
cd hello-world
zig init

输出应该是：

info: created build.zig
info: created build.zig.zon
info: created src/main.zig
info: created src/root.zig
info: see `zig build --help` for a menu of options

接着运行 zig build run，就会编译出可执行文件并运行它，最终输出：

All your codebase are belong to us.
Run `zig build test` to run the tests.

恭喜，你的 Zig 已经安装好并可以使用了！

下一步

看看入门部分中的其他资料，务必找到与你所用 Zig 版本对应的文档（注意：nightly 构建应使用 master 文档），也可以读一读 zig.guide。

Zig 是一个年轻的项目，遗憾的是，我们暂时还没有能力为所有内容编写详尽的文档和学习资料。因此，遇到困难时可以考虑加入现有的某个 Zig 社区寻求帮助，也可以关注 Zig SHOWTIME 这类活动。

最后，如果你喜欢 Zig，并希望帮助加快它的开发，请考虑向 Zig 软件基金会捐款。
