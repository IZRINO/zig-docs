选择发布版本还是开发版本？

总体而言，带版本标签的正式发布版本更适合依赖稳定环境并用于生产的实际工程项目；而开发构建版本（Development Builds）则面向希望体验最新语言演进或参与 Zig 本身开发的贡献者。

Zig 的安装包是完全自包含的独立压缩包，解压后可以存放在操作系统的任意目录下，不同版本的 Zig 可以完美共存且互不干扰。

安装 Zig

直接下载安装包

这是获取 Zig 最直接简便的方式：从下载页面获取适合你操作系统的压缩包，将其解压至指定目录，然后把该目录添加到 PATH 环境变量中，即可在终端的任意位置调用 zig。

Windows

在 Windows 上配置 PATH 环境变量，请在 PowerShell 中执行以下任一脚本片段。你可以选择系统级全局生效（需要以管理员身份运行 PowerShell）或仅对当前用户生效，并务必将路径替换为你实际存放 Zig 的目录。注意：C: 前面的分号 ; 是必需的分隔符，并非拼写错误。

系统级全局配置（管理员权限 PowerShell）：

[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "Machine") + ";C:\your-path\zig-windows-x86_64-your-version",
   "Machine"
)

当前用户配置（普通用户权限 PowerShell）：

[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\your-path\zig-windows-x86_64-your-version",
   "User"
)

配置完成后，请重启 PowerShell 终端使环境变量生效。

macOS

将解压出的 zig 可执行文件所在目录添加到 PATH 环境变量中。

通常只需在终端的启动脚本配置文件（如 .profile、.bashrc、.zshrc 等）中添加一行 export 语句：

export PATH=$PATH:~/path/to/zig

配置完成后，可以执行 source <配置文件> 使其立即生效，或者直接重启终端。

通过包管理器安装

Windows

WinGet
可以通过 WinGet 安装 Zig：

winget install -e --id zig.zig

Chocolatey
可以通过 Chocolatey 安装 Zig：

choco install zig

Scoop
可以通过 Scoop 安装 Zig：

scoop install zig

最新开发分支构建版本（dev build）：

scoop bucket add versions
scoop install versions/zig-dev

macOS

Homebrew
最新正式发布版本：

brew install zig

MacPorts

sudo port install zig

Linux

许多 Linux 发行版的官方包管理器与软件仓库中也已收录了 Zig。

推荐开发工具

语法高亮与语言服务器（LSP）

所有主流文本编辑器均提供对 Zig 的语法高亮支持。部分编辑器已原生内置，其余则可通过安装插件获得支持。

如果你希望在编辑器中获得代码自动补全、跳转定义等深度集成体验，推荐使用官方语言服务器项目 zigtools/zls。

如果你想探索更多社区开发工具，可以查阅工具一览（Tools）章节。

运行 Hello World

如果你已经顺利完成上述安装与配置，现在应该可以在终端中直接调用 Zig 编译器了。让我们创建第一个 Zig 项目来快速检验一下！

进入你的代码工程目录并运行：

mkdir hello-world
cd hello-world
zig init

终端将输出类似如下信息：

info: created build.zig
info: created build.zig.zon
info: created src/main.zig
info: created src/root.zig
info: see `zig build --help` for a menu of options

接下来执行 zig build run，构建系统将编译并运行该程序，最终输出：

All your codebase are belong to us.
Run `zig build test` to run the tests.

恭喜你！Zig 开发环境已成功安装并运行！

后续学习建议

欢迎继续阅读入门模块中的其他章节。请务必选择与你的 Zig 版本相匹配的官方文档（注意：使用 Nightly 开发版本的读者请查阅 master 分支文档），同时非常推荐阅读社区编写的教程 zig.guide。

Zig 是一门年轻而充满活力的语言，文档与学习资料仍在持续完善中。如果在探索过程中遇到任何疑问，欢迎加入活跃的 Zig 中文与全球社区获取帮助，也可以关注诸如 Zig SHOWTIME 等精彩的社区活动与技术分享。

最后，如果你热爱 Zig 并希望加速它的发展，欢迎考虑向 Zig 软件基金会（ZSF）提供捐赠支持。
